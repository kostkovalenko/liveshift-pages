# LiveShift GitHub Pages

Static pages for:
- Privacy Policy (English)
- Privacy Policy (Ukrainian)
- Support page

## Files

- `index.html`
- `privacy-policy-en.html`
- `privacy-policy-uk.html`
- `support.html`

## Quick publish

1. Create a new GitHub repository, for example `liveshift-pages`
2. Upload these files to the root of that repository
3. In GitHub:
   - `Settings`
   - `Pages`
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Save

## Example URLs

If your repo is `https://github.com/kostkovalenko/liveshift-pages`, then Pages will usually be:

`https://kostkovalenko.github.io/liveshift-pages/`

Pages:
- `https://kostkovalenko.github.io/liveshift-pages/privacy-policy-en.html`
- `https://kostkovalenko.github.io/liveshift-pages/privacy-policy-uk.html`
- `https://kostkovalenko.github.io/liveshift-pages/support.html`

## Suggested App Store Connect usage

- Privacy Policy URL:
  - use the English page, or the main index page
- Support URL:
  - use `support.html`
- Terms of Use:
  - if using Apple's standard EULA, add this link in metadata:
  - `https://www.apple.com/legal/internet-services/itunes/dev/stdeula/`
